# ATLAS Integration Fabric — GitHub Pages legal site

Sitio estático preparado para GitHub Pages.

## Archivos
- `index.html`
- `privacy.html`
- `terms.html`
- `data-deletion.html`
- `.nojekyll`

## Publicación
1. Cree un repositorio público, por ejemplo `atlas-legal`.
2. Suba todos los archivos a la rama `main`.
3. GitHub → Settings → Pages.
4. Build and deployment → Deploy from a branch.
5. Branch `main`, folder `/ (root)`.
6. Guarde y espere a que GitHub publique la URL.

Campos recomendados en Meta:
- Política de privacidad → `.../privacy.html`
- Condiciones del servicio → `.../terms.html`
- Eliminación de datos → `.../data-deletion.html`
