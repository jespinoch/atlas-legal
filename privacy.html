Política de Privacidad de ATLAS Integration Fabric

Última actualización: 7 de octubre de 2026

1. Alcance

ATLAS Integration Fabric puede conectarse, con autorización del usuario, a servicios de terceros como Meta/Facebook/Instagram, YouTube/Google, Slack y otras integraciones habilitadas.

2. Datos tratados

Según la integración y los permisos concedidos, ATLAS puede tratar identificadores de cuenta, canal o página, nombres de usuario, metadatos básicos, información necesaria para la funcionalidad solicitada, credenciales técnicas de acceso y registros técnicos mínimos.

ATLAS no solicita las contraseñas de los servicios externos. La autenticación se realiza mediante los mecanismos oficiales de cada proveedor.

3. Finalidad

Los datos se utilizan para conectar y validar cuentas autorizadas, leer o procesar información solicitada, ejecutar acciones autorizadas, mantener integraciones, diagnosticar errores y proteger la seguridad del servicio.

4. Control del usuario

El usuario puede revocar el acceso desde el proveedor correspondiente y solicitar la desconexión o eliminación de los datos asociados.

5. Compartición

ATLAS no vende datos personales ni los comparte con fines publicitarios. Solo podrán intervenir proveedores técnicos necesarios para operar la aplicación o cuando exista una obligación legal válida.

6. Seguridad y conservación

ATLAS aplica medidas razonables para limitar el acceso no autorizado a datos y credenciales. La información se conserva solo mientras sea necesaria para prestar la funcionalidad autorizada, resolver incidencias o cumplir obligaciones aplicables.

7. Servicios de terceros

Las integraciones también están sujetas a las políticas y condiciones de Meta, Google, YouTube, Slack y otros proveedores correspondientes.

8. Derechos y eliminación

Para solicitar acceso, corrección o eliminación de datos, consulte las instrucciones de eliminación de datos.
